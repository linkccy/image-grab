🎯

安装步骤

四步装好，一分钟

插件还没上架应用商店，用「加载已解压的扩展程序」安装，开发者模式下即可使用。

  1. 1

    下载并解压

    点下面的「下载插件」拿到 ZIP，解压到一个固定的文件夹（别放下载目录，可能被清理）。

  2. 2

    打开扩展管理页

    地址栏输入 chrome://extensions 回车；Edge 用 edge://extensions。

  3. 3

    打开开发者模式

    页面右上角有个「开发者模式」开关，打开后才会出现加载按钮。

  4. 4

    加载已解压的扩展程序

    点左上角「加载已解压的扩展程序」，选中刚解压出来的 extension 文件夹，看到「图提取」就成功了。

用的时候：打开任意商品详情页，右下角会出现紫色的「获取图片」按钮； 如果没出现，先刷新页面，或者确认当前页是商品详情页而不是列表页。
